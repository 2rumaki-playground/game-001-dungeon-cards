- 移動距離：基本1マス
- ジャンプカードの着地距離：2マス先

## 戦闘
- 敵行動回数：1体につき1ターン1回（タイプ別の移動処理は1回の行動内で完結する）
- 攻撃範囲：隣接1マス（隣接の定義は [glossary.md](./glossary.md) 参照：4近傍、上下左右のみ）

### 敵の種類
- 敵は **8種類**（通常敵・重装敵・俊敏敵・召喚敵・射撃敵・盾持ち敵・ミニボス・ボス）
- 通常敵・重装敵・俊敏敵・召喚敵・射撃敵・盾持ち敵の詳細な行動パターンは [enemies.md](./enemies.md) を参照
- ミニボス・ボスの特殊スキルは下記「ボス特殊スキル（v1.4）」節を参照

## ボス特殊スキル（v1.4）

### ミニボス: 強化攻撃（power_strike）
- 発動確率：30%（非隣接時の移動後に判定）
- ダメージ倍率：通常攻撃の2倍
- 予告：「ミニボスが力を溜めている…」（発動前ターン）
- 発動条件：予告後の次ターンで隣接時

### ボス: 範囲攻撃（area_attack）
- 発動確率：25%（非隣接時の移動後に判定）
- ダメージ：2
- 射程：マンハッタン距離2以内
- 予告：「ボスが大技を構えている…」（発動前ターン）
- 発動条件：予告後の次ターンで射程内

### 予告のUI表示
- ログ：上記の予告テキストを行動ログに表示
- 範囲ハイライト：影響範囲のタイルをスキル色で脈動オーバーレイ表示（alpha 0.1〜0.3）
- アイコン：敵のセル上部にスキルアイコンを表示（強化攻撃＝菱形、範囲攻撃＝二重円）
- Fog of War：未踏タイルにいる敵の予告は非表示、影響範囲も未踏タイルは除外

### ボス: 激昂（enrage）
- 発動条件：HP50%以下（自動発動、1回限り）
- 効果：攻撃ダメージ+2
- ログ：「ボスが激昂した」

## 行動ログ
- 行動ログ保持件数：50件（画面表示用）

### マップレイアウト（v1.2以前の固定レイアウト、参考情報）
- レイアウト方式：固定（外周が壁、内側が床）
- 外周壁：マップの境界（上下左右の端）はすべて壁タイル
- 内側床：外周を除く内側5×5マス（25マス）はすべて床タイル
- 配置可能な床タイル数：25マス

※ v1.3以降は階層別マップサイズのBSP生成方式が現行仕様。詳細は下記「階層別マップサイズ」節を参照。

### ランダム生成の再現性
- 本番実行時：シード固定なし（真のランダム）
- テスト実行時：シード指定可能（再現性確保）
- デバッグ実行時：シード表示・指定可能
- 詳細は [rules.md](./rules.md) の「ランダム配置の再現性方針」を参照

## カード交換（v1.2）

### 敵撃破時のカード獲得

#### 敵タイプとカードの対応

| 敵タイプ | 獲得カード |
|---------|-----------|
| 通常敵 | 移動カード |
| 重装敵 | 強攻撃カード |
| 俊敏敵 | ジャンプカード |
| 召喚敵 | 待機カード |
| 射撃敵 | 移動カード |
| 盾持ち敵 | 攻撃カード |
| ミニボス | 攻撃カード |
| ボス | 待機カード |

#### 獲得条件

| 敵タイプ | 条件 | 結合 |
|---------|------|------|
| 通常敵 | 撃破数 ≥ 3 | AND |
| 重装敵 | 撃破数 ≥ 2 | AND |
| 俊敏敵 | 撃破数 ≥ 2 かつ 被弾数 ≥ 1 | AND |
| 召喚敵 | 撃破数 ≥ 2 | AND |
| 射撃敵 | 撃破数 ≥ 3 | AND |
| 盾持ち敵 | 撃破数 ≥ 2 | AND |
| ミニボス | 撃破数 ≥ 1 | AND |
| ボス | 撃破数 ≥ 1 | AND |

- 撃破数・被弾数はラン単位で累計（フロアをまたいで持続、ゲーム開始時に0リセット）
- 条件を満たした状態で敵を撃破するとカード交換画面が表示される

※ 条件の閾値はバランス調整で変更される前提

### キャラクタープロフィール

| ID | 性別 | 年齢帯 | 身体的特徴 | イメージ |
|----|------|--------|-----------|---------|
| `brave` | 男性 | 20代前半 | がっしりした体格 | 剣士 |
| `cautious` | 女性 | 不詳 | 眼鏡 | 分析者 |
| `cheerful` | 女性 | 10代後半 | 小柄で身軽 | 冒険好き |

### 口調ルール

| ID | 一人称 | 代表的語尾 | 口調の特徴 | 備考 |
|----|--------|-----------|-----------|------|
| `brave` | 俺 | 〜だ！/ 〜ぞ！/ 〜からな！ | 力強い断定形・命令形 | 短文では一人称省略可 |
| `cautious` | 使わない | 〜を確認 / 〜だ / 〜する / 〜ねば | 分析的・報告調、客観的表現 | 主語を避け状況描写で表現 |
| `cheerful` | 使わない | 〜だよ！/ 〜だね！/ 〜よ〜 / 〜〜！ | 軽快、感嘆詞・伸ばし音多用 | — |
| `stoic` | 使わない | 体言止め / …（省略） | 最短・最小限、「…」多用 | レアセリフでのみ「俺」使用可 |
| `curious` | 使わない | 〜だろう / 〜かな / 〜のか | 疑問形・推測形、探究的 | — |

- レアセリフはギャップ表現として設計されており、通常の口調ルールの例外が許容される
- コンテキスト発話（状況依存セリフ）は通常発話の延長であり、通常の口調ルールに従う

- 性格一覧：`PERSONALITIES` 配列（5種）
- デフォルト性格：`DEFAULT_PERSONALITY` = `brave`
- 通常セリフ：各性格 × 12イベント × 各5バリエーション = 計300パターン
- レアセリフ：各性格 × 8イベント × 各1バリエーション = 計40パターン（デフォルト発話時に低確率で出現）
