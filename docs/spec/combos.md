# コンボシステム

## 概要

同一ターン内のカード使用順序に基づき、特定の組み合わせでボーナスが発生するシステム。

## 基本ルール

### 発動タイミング

- **即時発動**：コンボ条件を満たすカードが使用扱いとなった瞬間に、そのカードの効果にボーナスが適用される
- 「使用扱い」の定義は [cards.md](./cards.md) の属性バランスシステムの記載に準ずる

### 判定対象

- コンボの判定は **直前に使用したカードのカードタイプ** に基づく
- 「直前」とは、同一ターン内で直前に使用扱いとなったカード1枚を指す
- ターン最初のカード使用時は直前のカードが存在しないため、コンボは発動しない
- ターンをまたいだコンボは成立しない（毎ターン、使用履歴はリセットされる）

### 重複発動

- 同一コンボは **条件を満たすたびに発動** する
- 例：攻撃→攻撃→攻撃 と使用した場合、連撃コンボが2回発動する（2枚目と3枚目のそれぞれにボーナスが適用される）

### 判定に使用するカードタイプ

- 各コンボ条件に記載されたカードタイプ（CardType）のみが対象
- 「攻撃」は `attack` のみを指す（`strong_attack` は含まない）
- 「移動」は `move` のみを指す（`jump` は含まない）

---

## コンボ一覧

### 突撃（charge）

| 項目 | 内容 |
|------|------|
| トリガー | `move` → `attack` |
| 追加条件 | 移動カードと攻撃カードの **方向パラメータが同一** であること |
| 効果 | 攻撃カードのダメージにコンボボーナスを加算（値は [constants.md](./constants.md) 参照） |
| 効果の適用 | 攻撃の成立・不成立にかかわらず、コンボボーナスは攻撃ダメージに加算される。ただし攻撃不成立時はダメージ自体が発生しないため、実質的にボーナスは無効となる |

- 移動が成功した場合にのみ突撃コンボが成立する（移動失敗時は `comboHistory.lastDirection` が `null` として記録されるため、同方向条件を満たせない）
- 「突撃（charge）予告」の表示条件は `comboHistory.lastCardType === "move"` かつ `comboHistory.lastDirection !== null` を前提とし、移動失敗時（`null` の場合）は予告は表示されない（後述の「#### 突撃（charge）予告」の条件も同一とする）
- コンボボーナスは属性ボーナスとは独立して加算される

### 連撃（chain）

| 項目 | 内容 |
|------|------|
| トリガー | `attack` → `attack` |
| 追加条件 | なし |
| 効果 | 2枚目の攻撃カードのダメージにコンボボーナスを加算（値は [constants.md](./constants.md) 参照） |
| 効果の適用 | 攻撃の成立・不成立にかかわらず、コンボボーナスは攻撃ダメージに加算される。ただし攻撃不成立時はダメージ自体が発生しないため、実質的にボーナスは無効となる |

- 1枚目の攻撃が不成立でも、使用扱いとなるためコンボ判定の対象になる
- コンボボーナスは属性ボーナスとは独立して加算される

---

## ダメージ計算順序

コンボボーナスを含むダメージ計算は以下の順序で行う：

1. カードの基本ダメージを決定する（[constants.md](./constants.md) 参照）
2. 基本ダメージに対してコンボボーナスを適用する
3. コンボボーナス適用後のダメージに対して属性ボーナスを適用する

ダメージ計算の具体的な式・補正値や最終ダメージの下限値などの共通ルールは、[rules.md](./rules.md) および [cards.md](./cards.md), [constants.md](./constants.md) 側で定義する。

## コンボ予告表示

### 概要

次のカード使用で発動可能なコンボを、手札カードの枠線強調で事前にプレイヤーに示す。
プレイヤーが戦略的な判断を行えるよう、コンボの成立条件を視覚的に提示する。

### 表示条件

- `comboHistory` が存在する場合（＝同一ターン内で1枚以上カードを使用済み）に**常時表示**する
- ターン開始直後（`comboHistory` が `null`）は表示しない

### 対象カード

手札内の `attack` タイプのカードのみが予告表示の対象となる。

- `strong_attack`, `jump`, `wait` はコンボ対象外のため予告表示しない
- `move` カードは現行コンボの「次のカード」側にならないため予告表示しない

### 表示方法

枠線の色をオレンジに変更することで、コンボ発動可能を示す。静的表示（アニメーションなし）。

#### 連撃（chain）予告

- **条件**: `comboHistory.lastCardType === "attack"`
- **表示**: 対象カードの **全4辺** をオレンジで強調
- **理由**: 方向条件がないため、どの方向に攻撃してもコンボが確定する

#### 突撃（charge）予告

- **条件**: `comboHistory.lastCardType === "move"` かつ `comboHistory.lastDirection !== null`
- **表示**: 対象カードの **前回の移動方向に対応する1辺のみ** をオレンジで強調
  - 例: 直前の移動が右方向 → 攻撃カードの右辺のみ強調
- **理由**: 同方向の攻撃でのみコンボが成立するため、成立方向を直感的に示す

### 表示の排他性

直前のカードは `move` または `attack` のいずれか一方のため、連撃予告と突撃予告が同時に表示されることはない。
