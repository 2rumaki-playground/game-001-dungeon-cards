# カード仕様

## 共通仕様
すべてのカードは以下を持つ：
- 名前
- 効果
- 使用条件

### 方向パラメータについて
一部のカード（移動カード、魔法カードなど）は、カード使用時に**方向を選択**する必要がある。
- 方向はカードの固有属性ではなく、**使用時のパラメータ**として扱う
- 各カードインスタンスはユニークなIDを持ち、同じ種別のカードがデッキ内に複数枚存在する
- 使用時にプレイヤーが上/下/左/右の4方向から選択する
- この設計により、データ管理（カードID、重複カード数、UI表示）がシンプルになる

## 移動カード

### 仕様
- カード種別：移動カード（CardType: `"move"`。同種のカードが複数枚デッキに存在し得る）
- **方向パラメータ**：使用時にプレイヤーが方向を選択（上 / 下 / 左 / 右）
- 効果：選択した方向に1マス移動
- 移動失敗条件（いずれの場合もカードは使用済みとなる）：
  - 移動先がマップ外（境界を超える場合）
  - 移動先が壁タイルまたはひび割れ壁
  - 移動先に敵が存在する場合 → **体当たり**が発生（下記参照）

#### 体当たり（移動先に敵がいる場合）
- 移動先に敵が存在する場合、プレイヤーは移動せず「体当たり」が発生する
- 敵に体当たりダメージ（レベルボーナスなし、カードXP付与なし。ダメージ量は [constants.md](./constants.md) 参照）
- プレイヤーに体当たり反動ダメージ（ダメージ量は [constants.md](./constants.md) 参照）
- 処理順：敵ダメージ → 自傷ダメージ → ゲームオーバー判定（相打ちあり）
- プレイヤー位置は移動しない（敵撃破時も）
- コンボ履歴：`lastDirection: null`（移動失敗扱い、突撃コンボ不成立）
- 盾持ち敵：`applyDamageToEnemy` を通す（プレイヤーが受ける体当たりダメージを半減［端数切り捨て］し、その分だけ敵に与える。盾は消費される）
- 移動成功時、移動先のタイルに応じた効果が発生する
  - 階段タイルに到達した場合：階層遷移が発生（詳細は [rules.md](./rules.md) の「階層遷移」を参照）

### データ表現
- 移動カードのカード種別（CardType）は `"move"` である
- 各カードインスタンスはユニークなID（例：`card-1`, `card-2`）を持ち、種別（type）で区別される
- デッキ内では同じ種別のカードが複数枚存在する（枚数は [constants.md](./constants.md) を参照）
- カード使用時、UIで4方向から1つを選択するインターフェースを提供する
- テストでは `{cardId: "card-1", direction: "up"}` のような形式で表現可能

## ファイアボルト

### 仕様
- カード種別：ファイアボルト（CardType: `"fire"`。同種のカードが複数枚デッキに存在し得る）
- **方向パラメータ**：使用時にプレイヤーが方向を選択（上 / 下 / 左 / 右）
- 効果：選択した方向1マス先の敵にダメージを与える（ダメージ量は [constants.md](./constants.md) 参照）

### 攻撃の成立条件
攻撃が成立するのは以下の条件をすべて満たす場合のみ：
- 指定方向1マス先がマップ内（境界内）である
- 指定方向1マス先が壁タイルまたはひび割れ壁ではない
- 指定方向1マス先に敵が存在する

### 攻撃の不成立
攻撃が不成立となるケース：
- 指定方向1マス先がマップ外（境界を超える場合）
- 指定方向1マス先が壁タイルまたはひび割れ壁
- 指定方向1マス先に敵が存在しない（床、階段、またはプレイヤー自身のみの場合）

**いずれの場合もカードは使用済みとなる**

### Lv3特殊効果: 貫通
- 解放レベル: 3（`CARD_LEVEL_PIERCE`、数値は [constants.md](./constants.md) 参照）
- 攻撃方向の最初の敵にダメージを与え、撃破時に余剰ダメージ（overkill）が発生した場合、同方向の次の敵にoverkillダメージを適用する
- 伝播は1回のみ（連鎖しない）
- 次の敵の探索は射程制限なし（壁/ひび割れ壁またはマップ外まで走査）

### Lv5特殊効果: 射程延長
- 解放レベル: 5（`CARD_LEVEL_RANGE_EXTEND`、射程: `FIRE_EXTENDED_RANGE`、具体値は [constants.md](./constants.md) 参照）
- `FIRE_EXTENDED_RANGE` マス先までの最初の敵を攻撃対象とする（壁/ひび割れ壁で走査停止）
- このレベルでは、ファイアボルトの基本仕様における「指定方向1マス先に敵がいること」という成立条件は、「指定方向最大 `FIRE_EXTENDED_RANGE` マス先までの最初の敵が存在すること」に置き換わる
- Lv3の貫通効果も保持される（射程 `FIRE_EXTENDED_RANGE` でヒットした敵を撃破時、さらに奥の敵にoverkill伝播）

### データ表現
- ファイアボルトのカード種別（CardType）は `"fire"` である
- 各カードインスタンスはユニークなID（例：`card-1`, `card-2`）を持ち、種別（type）で区別される
- デッキ内では同じ種別のカードが複数枚存在する（枚数は [constants.md](./constants.md) を参照）
- カード使用時、UIで4方向から1つを選択するインターフェースを提供する
- テストでは `{cardId: "card-1", direction: "down"}` のような形式で表現可能

## サンダー

### 仕様
- カード種別：サンダー（CardType: `"thunder"`。同種のカードが複数枚デッキに存在し得る）
- **方向パラメータ**：使用時にプレイヤーが方向を選択（上 / 下 / 左 / 右）
- 効果：選択した方向1マス先の敵に大ダメージを与える（ダメージ量は [constants.md](./constants.md) 参照）

### 攻撃の成立条件
攻撃が成立するのは以下の条件をすべて満たす場合のみ：
- 指定方向1マス先がマップ内（境界内）である
- 指定方向1マス先が壁タイルまたはひび割れ壁ではない
- 指定方向1マス先に敵が存在する

### 攻撃の不成立
攻撃が不成立となるケース：
- 指定方向1マス先がマップ外（境界を超える場合）
- 指定方向1マス先が壁タイル
- 指定方向1マス先に敵が存在しない（床、階段、またはプレイヤー自身のみの場合）

**いずれの場合もカードは使用済みとなる（敵へのダメージは発生しない）**

> 指定方向1マス先がひび割れ壁の場合：攻撃は不成立（敵へのダメージなし）だが、壁を破壊して床タイルに変化させる（詳細は [rules.md](./rules.md) の「ひび割れ壁の破壊条件」を参照）。カードは使用済みとなる

### Lv3特殊効果: ノックバック
- 解放レベル: 3（`CARD_LEVEL_KNOCKBACK`、数値は [constants.md](./constants.md) 参照）
- 攻撃後、敵が生存していれば攻撃方向に1マス吹き飛ばす
- ノックバック先の条件: マップ内 ∧ 壁またはひび割れ壁でない ∧ プレイヤーがいない ∧ 他の敵がいない
- 条件を満たさない場合、ノックバックは発生しない（ダメージは入る）

### Lv5特殊効果: 衝撃波
- 解放レベル: 5（`CARD_LEVEL_SHOCKWAVE`、数値は [constants.md](./constants.md) 参照）
- 正面+左右の3マスにフルダメージを与える
- 正面に敵が必須（正面が壁/ひび割れ壁/空/マップ外の場合は空振り、サイドのみでは発動しない）
- ターゲット3マス: 正面 + サイド(反時計回り) + サイド(時計回り)
- `delta = (dx, dy)` を「画面座標系（原点左上、yが下方向に増加）」での攻撃方向ベクトルとするとき、
  - サイド(反時計回り)のオフセットは `(-dy, dx)`（攻撃方向を反時計回りに90度回転）
  - サイド(時計回り)のオフセットは `(dy, -dx)`（攻撃方向を時計回りに90度回転）
- 処理順: 正面 → サイド(反時計回り) → サイド(時計回り)（state連鎖）
- 各サイドは独立判定（壁/ひび割れ壁/マップ外ならスキップ）
- 衝撃波後、生存した敵にノックバック（攻撃方向に1マス、処理順: 正面 → サイド）
- Lv3のノックバック効果も保持される

### データ表現
- サンダーのカード種別（CardType）は `"thunder"` である
- 各カードインスタンスはユニークなID（例：`card-1`, `card-2`）を持ち、種別（type）で区別される
- デッキ内では同じ種別のカードが複数枚存在する（枚数は [constants.md](./constants.md) を参照）
- カード使用時、UIで4方向から1つを選択するインターフェースを提供する
- テストでは `{cardId: "card-1", direction: "up"}` のような形式で表現可能

## ジャンプカード

### 仕様
- カード種別：ジャンプ（CardType: "jump"。同種のカードが複数枚デッキに存在し得る）
- **方向パラメータ**：使用時にプレイヤーが方向を選択（上 / 下 / 左 / 右）
- 効果：選択した方向の**2マス先**に直接着地する（1マス先を飛び越える）

#### 解決処理
ジャンプカードは以下の順序で処理される：

1. **着地先（2マス先）の判定**
   - 着地先がマップ外の場合：
     - **ジャンプ失敗**：プレイヤーは移動せず、その場に留まる
     - カードは使用済みとなる
     - 処理終了
   - 着地先が壁タイルまたはひび割れ壁の場合：
     - **ジャンプ失敗**：プレイヤーは移動せず、その場に留まる
     - カードは使用済みとなる
     - 処理終了
   - 着地先に敵が存在する場合：
     - **ジャンプ失敗**：プレイヤーは移動せず、その場に留まる
     - カードは使用済みとなる
     - 処理終了
   - 着地先が床、階段、または特殊タイルで、敵が存在しない場合：
     - **ジャンプ成功**：2マス先に直接移動
     - 着地先の判定へ進む

2. **着地先の階段判定**
   - 着地先が階段の場合：
     - **階層遷移が発生**（[rules.md](./rules.md) の「階層遷移」を参照）
     - 処理終了
   - 着地先が床または特殊タイルの場合：
     - 特殊タイル効果判定へ進む

3. **着地先の特殊タイル効果**
   - 着地先が特殊タイルの場合：
     - 着地先のタイル効果のみ発動する
   - 着地先が通常床の場合：
     - 処理終了

#### 飛び越えルール
- 1マス先の**敵・壁・階段・特殊タイル**を飛び越えられる
- 飛び越えたマスの効果は**一切発動しない**（罠ダメージなし、宝箱開かない、階段も無視）
- 1マス先が壁でも、2マス先が有効な床タイルであればジャンプ可能

#### 重要な仕様
- **カードは常に使用済みとなる**（ジャンプが失敗した場合も含む）
- 着地先のみで階段判定・特殊タイル効果判定が行われる
- 他のキャラクター（敵）との衝突では、ジャンプが失敗するのみで、ダメージは発生しない（魔法カードではないため）
- ※ 移動可否判定の詳細は `rules.md` の「移動可否の判定」を参照（正）

### データ表現
- ジャンプカードのカード種別（CardType）は `"jump"` である
- 各カードインスタンスはユニークなID（例：`card-1`, `card-2`）を持ち、種別（type）で区別される
- デッキ内では同じ種別のカードが複数枚存在する（枚数は [constants.md](./constants.md) を参照）
- カード使用時、UIで4方向から1つを選択するインターフェースを提供する
- テストでは `{cardId: "card-1", direction: "right"}` のような形式で表現可能

## カードレベル・経験値

### 概要
カードは敵を倒すことで経験値（XP）を獲得し、レベルアップする。

### Card型
すべてのカードは以下のフィールドを持つ：
- `level`（初期値: 1）
- `exp`（初期値: 0）

### XP獲得条件
- 敵撃破時、その攻撃に使用したカード（`fire` または `thunder`）にXP+1が付与される
- 移動・ジャンプ・待機カードではXPは獲得されない
- 敵1体撃破 = XP+1（敵タイプによる差異なし）

### レベルアップ
- XPテーブルおよびレベル上限は [constants.md](./constants.md) を参照
- ファイアボルト/サンダーはレベルに応じてダメージボーナスが加算される（数値は [constants.md](./constants.md) の `CARD_LEVEL_DAMAGE_BONUS` を参照）

## カード統計

### 概要
各カードは統計情報（`stats`）を保持し、ツールチップに表示する。手札4枚の少数精鋭構成に「一緒に戦ってきた」という物語性を持たせることが目的。

### CardStats型
すべてのカードは以下の統計フィールドを持つ（初期値はすべて0）：
- `useCount` — 使用回数
- `defeatCount` — 撃破数
- `maxSingleDamage` — 最大単発ダメージ

### 記録タイミング
- **useCount**: カードが使用済みになるタイミング（`markCardAsPlayed`）で+1。全カード種別が対象
- **defeatCount**: 敵撃破時、その攻撃に使用したカードの撃破数を+1。`fire` / `thunder` のみ対象
- **maxSingleDamage**: 敵にダメージを与えた際、実効ダメージ（`min(effectiveDamage, enemy.hp)`）が既存の最大値を超えた場合に更新。`fire` / `thunder` のみ対象

### ツールチップ表示
- カードが1回以上使用された場合（`useCount > 0`）にのみ統計セクションを表示
- 使用回数は全カード種別で表示
- 撃破数・最大ダメージは `fire` / `thunder` のみ表示
