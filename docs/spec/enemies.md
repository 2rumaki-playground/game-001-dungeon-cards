# 敵タイプ仕様

## 概要

敵は複数のタイプに分類され、タイプごとに異なるパラメータと行動パターンを持つ。
これにより、プレイヤーは敵タイプに応じてカードの使い分けを求められる。

各タイプのパラメータ（HP、攻撃ダメージなど）は [constants.md](./constants.md) を参照。

---

## 敵タイプ一覧

### 通常敵（ノーマル）

基準となるバランスの敵。現行仕様と同一の挙動を持つ。

- パラメータ：[constants.md](./constants.md) の「敵タイプ別パラメータ」を参照
- 移動パターン：BFS最短経路（[rules.md](./rules.md) の「敵の移動（近づく）」を参照）
- 攻撃条件：隣接時にプレイヤーを攻撃（[rules.md](./rules.md) の「敵の攻撃」を参照）

### 重装敵（ヘビー）

高耐久・高火力の静止型。交戦するか回避するかの判断を要求する。

- パラメータ：[constants.md](./constants.md) の「敵タイプ別パラメータ」を参照
- 移動パターン：**移動しない（静止）**
- 攻撃条件：隣接時にプレイヤーを攻撃（[rules.md](./rules.md) の「敵の攻撃」を参照）

#### 戦略的意図

- **強攻撃カードの使用を促す**：複数回の小ダメージ攻撃よりも、高威力カードを交えたコンボの方が効率的
- 静止型のため、プレイヤーが「交戦 or 回避」を選択できる
- 交戦時は被ダメージが重い → 位置取り・タイミングが重要

### 俊敏敵（スカウト）

低耐久・高機動。素早い接近でプレイヤーの位置取りを脅かす。

- パラメータ：[constants.md](./constants.md) の「敵タイプ別パラメータ」を参照
- 移動パターン：BFS最短経路で1マス移動を、[constants.md](./constants.md) の「敵タイプ別パラメータ」で定義された移動距離の回数だけ繰り返す
- 攻撃条件：隣接時にプレイヤーを攻撃（[rules.md](./rules.md) の「敵の攻撃」を参照）

#### 戦略的意図

- **ジャンプカード・移動カードの使用を促す**：逃げにくいため位置取りが重要
- 脆いが接近が速い

### 召喚敵（サモナー）

低耐久・静止型の支援ユニット。一定間隔で通常敵を召喚し、数的有利を作る。

- パラメータ：[constants.md](./constants.md) の「敵タイプ別パラメータ」を参照
- 移動パターン：**移動しない（静止）**
- 攻撃条件：**攻撃しない**（隣接時は後退を試みる）
- **召喚クールダウン**: 一定ターンごとに召喚を行う（`summonCooldown` によるカウンタ管理。具体的なターン数・カウンタ仕様は [constants.md](./constants.md) の「召喚クールダウン」を参照）

#### 行動テーブル

| 条件 | 行動 |
|------|------|
| 索敵範囲外 | 待機 |
| 部屋内 + プレイヤー不在 | 待機 |
| 隣接 + 後退可能 | 後退（プレイヤーと反対方向に1マス移動） |
| 隣接 + 後退不可 | 待機 |
| 非隣接 + 召喚ターン（cooldown=0） + 8近傍に空きマスあり | 通常敵を1体召喚 |
| 非隣接 + 召喚ターン + 空きマスなし | 待機（cooldown消費なし） |
| 非隣接 + 非召喚ターン（cooldown>0） | 待機（cooldown-1） |

#### 召喚条件

- **召喚位置**: 隣接8マス（斜め含む）の空きマス（床タイルおよび `trap` / `treasure` / `rest_area` などのプレイヤーが通行可能な特殊タイル。敵・プレイヤー・壁・階段なし）からランダム選択
- 召喚後、クールダウンをリセット

#### 後退ルール

- プレイヤーと反対方向のマスに後退を試みる
- 後退先が移動不可（壁・階段・他の敵・マップ外）の場合は待機

#### 戦略的意図

- **早期撃破を促す**：放置すると雑魚敵が増え続け、数的不利に陥る
- **位置取りの重要性**：召喚敵に近づくと後退するため、追い詰める戦略が必要
- 召喚される敵は通常敵のため、個々の脅威は低い

### 盾持ち敵（シールド）

高耐久のBFS追従型。初撃を半減する盾を持ち、コンボの組み立て（弱攻撃で盾消費→強攻撃で本体）を要求する。

- パラメータ：[constants.md](./constants.md) の「敵タイプ別パラメータ」を参照
- 移動パターン：BFS最短経路（通常敵と同じ）
- 攻撃条件：隣接時にプレイヤーを攻撃（[rules.md](./rules.md) の「敵の攻撃」を参照）
- **初撃半減**: 1プレイヤーターン中に受ける最初の攻撃ダメージを半減（端数切り捨て）。2撃目以降はフルダメージ
- **盾リセット**: 敵ターン開始時に盾をリセット（＝毎プレイヤーターン中に1回発動）

#### 戦略的意図

- **コンボの組み立てを促す**：弱攻撃で盾を消費してから強攻撃を当てる、カード順序の判断が重要
- BFS追従で接近するため、回避は困難
- 通常敵と同程度のHP・攻撃力のため、盾をうまく処理すれば脅威は低い

### 射撃敵（レンジド）

低耐久・遠距離攻撃型。直線上の射程内から射撃を行い、隣接時は後退して距離を取る。

- パラメータ：[constants.md](./constants.md) の「敵タイプ別パラメータ」を参照
- 移動パターン：自発的な追従移動をしない（後退は専用ロジック）
- 攻撃条件：下記「射撃敵の行動テーブル」を参照

#### 射撃敵の行動テーブル

| 状況 | 行動 |
|------|------|
| 非隣接 + 直線上射程内（壁遮蔽なし） | 射撃（attackDamage分のダメージ） |
| 非隣接 + 射程外 or 直線外 or 壁遮蔽 | 待機 |
| 隣接 + 後退可能 | 後退のみ（射撃しない） |
| 隣接 + 後退不可（壁・敵・マップ外・階段） | その場で射撃 |

#### 射撃条件

- **直線判定**：敵とプレイヤーが同じx座標または同じy座標にいること
- **射程判定**：マンハッタン距離が射程距離（[constants.md](./constants.md) 参照）以内であること
- **壁遮蔽判定（射線チェック）**：敵からプレイヤーまでの直線上に壁タイルがないこと

#### 後退ルール

- プレイヤーとの位置関係から反対方向に1マス後退を試みる
- 後退先が壁・他の敵・マップ外・階段の場合は後退不可
- 後退不可の場合はその場で射撃を行う
- 後退時は射撃を行わない

#### 戦略的意図

- **距離管理の判断を要求する**：接近して倒すか、射線を避けるかの選択
- 低HPだが遠距離から攻撃できるため、放置は危険
- 隣接すると逃げるため、追い詰めて倒す戦術が有効

## 行動パターン

### 共通ルール

すべての敵タイプに共通する行動ルール：

- 敵は1体ずつ行動する（[rules.md](./rules.md) の「敵ターン」を参照）
- プレイヤーに隣接している場合 → 攻撃
- 索敵範囲内（[constants.md](./constants.md) の「敵タイプ別パラメータ」参照） → タイプ別の移動パターンに従う
- 索敵範囲外 → 待機（何もしない）
- 行動回数・攻撃範囲は [constants.md](./constants.md) を参照

### 移動の共通制約

すべての敵タイプの移動に共通する制約（[rules.md](./rules.md) の「移動可否の判定」も参照）：

- 移動先が壁・マップ外・他の敵・プレイヤーの場合、移動失敗
- 移動先が階段タイルの場合、移動失敗（敵は階段に進入不可。[glossary.md](./glossary.md) の「階段タイル」参照）

### タイプ別移動パターン

#### 通常敵の移動

- [rules.md](./rules.md) の「敵の移動（近づく）」と同一
- 移動距離は [constants.md](./constants.md) の「敵タイプ別パラメータ」を参照
- BFS最短経路でプレイヤーに接近する（壁・階段を迂回）

#### 重装敵の移動

- **移動しない**
- 重装敵はプレイヤーに隣接していない場合、行動をスキップする
- 隣接時のみ攻撃を行う

#### 俊敏敵の移動

- [constants.md](./constants.md) の「敵タイプ別パラメータ」で定義された移動距離の回数だけ、1マス移動判定を繰り返す
- 各移動の方向決定は、移動時点の位置からBFS最短経路の最初の一歩を選択する

#### 盾持ち敵の移動

- 通常敵と同じBFS最短経路で移動
- 移動距離は [constants.md](./constants.md) の「敵タイプ別パラメータ」を参照

#### 射撃敵の移動

- **自発的な追従移動をしない**（moveDistance=0）
- 隣接時のみ、プレイヤーと反対方向に1マス後退を試みる
- 後退先の判定には「移動の共通制約」を適用する

##### 複数マス移動の解決手順

1. **1マス目の移動判定**
   - BFS最短経路でプレイヤーまでの最初の一歩の方向を決定
   - 同距離の経路が複数ある場合、固定優先順序（上 → 下 → 左 → 右）で選択
   - 「移動の共通制約」に該当する場合、移動失敗（その場に留まり、2マス目の移動も行わない）

2. **1マス目の隣接判定**
   - 1マス移動後にプレイヤーに隣接している場合、2マス目の移動は行わない
   - この時点では攻撃は行わない（攻撃は敵の行動開始時の隣接判定でのみ発生する）

3. **2マス目の移動判定**
   - 1マス移動後の位置からBFS最短経路を再計算
   - 1マス目と同じルールで方向を決定し、移動判定を行う
   - 「移動の共通制約」に該当する場合、移動失敗（1マス目の位置で停止）

## 階層別配置ルール

### 配置テーブル

敵の配置数は階層に応じて増加し（[constants.md](./constants.md) の「階層別敵配置数」参照）、タイプ構成も階層に応じて変化する。
具体的な数値は [constants.md](./constants.md) の「階層別敵配置テーブル」を参照。

| 階層帯 | 意図 |
|--------|------|
| 序盤 | 通常敵のみで基本ルールを学習 |
| 中盤前半 | 俊敏敵を導入し、位置取りの重要性を学ぶ |
| 中盤後半 | 重装敵を導入し、火力配分の判断を学ぶ |
| 終盤 | 全タイプ混在で、カードの使い分けを要求 |
| 高難度 | 上位タイプ中心の高難度構成 |

### バランス方針

- 序盤（階層1-2）は通常敵のみで基本ルールを学習させる
- 中盤（階層3-6）は新タイプを1種ずつ導入し、対処法を学ばせる
  - 6Fで射撃敵を初導入（5F中ボス後の次フロアで、遠距離攻撃への対処を学ばせる）
- 終盤（階層7+）は複数タイプを混在させ、カードの使い分けを要求する
  - heavy+scoutを常駐枠とし、3枠目はsummoner/rangedを**概ね2-3F間隔を目安に交互導入**する（ただしボス階層や高階層など一部は例外とし、詳細な構成は [constants.md](./constants.md) の「階層別敵配置テーブル」に従う）
- 配置数は階層に応じて増加し（[constants.md](./constants.md) 参照）、難易度はタイプ構成と配置数で調整する
