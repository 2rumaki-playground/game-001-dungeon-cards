# ビジョン / ゲーム概要

## ジャンル
- タイル制ローグライク × デッキ構築カードゲーム

## コアコンセプト
- ローグライクの「位置取り・間合い」
- カードゲームの「手札・リソース管理」
  を同時に考えさせるゲーム体験を目指す。

## プレイヤー体験
- 1手ごとに「移動か？攻撃か？」を選択
- AP (Action Point :アクションポイント) の制限により無駄な行動がリスクになる
- APコストの異なるカード（通常行動と強行動）の使い分けが戦略の鍵
- デッキ構築によってプレイ感が変化する（※v1.2以降で実装予定）

## v1での制約
- **デッキ構築なし**: 初期デッキ固定で全階層をプレイ
- カード入手・追加の手段は実装しない

## v1.2 のスコープ
- **デッキ構築の導入**: カードの入手・除去によるデッキカスタマイズ（詳細は [deckbuilding.md](./deckbuilding.md) を参照）
- レアリティシステムとカードプールの追加
- 新カード（回復カード、貫通攻撃カード）の追加

## v1 のゴール
- ダンジョンを進み、より深い階層へ到達する
- 明確な勝利条件は設定しない
