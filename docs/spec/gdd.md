# ゲームデザインドキュメント（GDD）

本ドキュメントはプレイヤー体験の目標値とデザイン判断の軸を定義する。
パラメータ調整や機能追加の際に「何を基準に良し悪しを判断するか」の根拠として参照する。

> 具体的な数値定数は [constants.md](./constants.md) を参照。本ドキュメントは目標と方針のみを扱う。

## 1ランの所要時間

| 指標 | 目標値 |
|------|--------|
| 1ラン（途中敗北を含む）の平均所要時間※1 | 10〜15分 |
| 通常階層1フロアあたりの平均所要時間※2 | 30〜45秒 |
| ボス階層1フロアあたりの所要時間※2 | 1〜2分 |
| 20Fクリア時の想定所要時間※3 | 15〜25分 |

- テンポよく遊べるカジュアル路線を目指す
- 短い休憩時間でも1ランを完走できる長さ
- 1階層あたりの時間が長くなりすぎる場合はマップサイズや敵配置数を見直す
- 平均到達階層は10〜12F前後を想定し、その範囲で上記の平均プレイ時間に収まるよう調整する
- ※1: 「1ラン」はタイトル画面からゲーム開始し、プレイヤーが死亡するか20Fをクリアするまでの1プレイ全体を指す。途中敗北を含む全プレイの平均（または中央値）として10〜15分を目標とする
- ※2: 所要時間は「思考時間＋行動時間」を含むテンポ感の指標であり、全階層に単純に掛け算して20Fクリア時間と一致することは想定していない
- ※3: 20Fまで到達してクリアするプレイは高難度クリアとして扱い、15〜25分程度までのプレイ時間を許容する

## 理想的な到達階層分布

急勾配型の難易度曲線を採用する。ボス階層が明確な壁となり、突破が上達の実感につながる設計。
以下の目標値は現行仕様の階層構成（全20F、[constants.md](./constants.md) 参照）を前提としている。

| プレイヤー層 | 到達階層目安 | 壁となる要素 |
|-------------|-------------|-------------|
| 初心者 | 3〜5F | 5Fミニボスが最初の壁 |
| 中級者 | 8〜12F | 10F大ボスが本格的な壁 |
| 熟練者 | 20Fクリア | 15F以降の高密度マップとボス連戦 |

- 初心者でも3Fまでは到達でき、ゲームの基本を学べる
- 5Fミニボスの突破が最初の達成感ポイント
- 10F大ボスを倒せるかどうかが中級者と上級者の分水嶺
- 20Fクリアは十分なスキルと判断力を要求する到達点

## カード使用率の目標

全カードが一定割合で使われることを目指す。「死にカード」を作らない設計方針。

> **使用率の定義**: カード種別ごとに「1ラン中にそのカードが1回以上使用されたランの割合」を全プレイヤーの全ランで集計した値。母数は集計期間内の総ラン数。

| 指標 | 目標値 |
|------|--------|
| 各カード種別の使用率 | 10%以上 |
| 使用率0%のカード種別 | 0（許容しない） |

- すべてのカード種別に「使うべき場面」が存在するように設計する
- 特定カードの使用率が著しく低い場合はコスト・効果の調整を検討する
- v1.2以降のデッキ構築では、プレイヤーの選択で使用率が偏ることは許容するが、「入れる価値がないカード」は作らない

## デザイン判断の軸

ゲーム全体の方向性を決めるトレードオフ方針。各項目について優先度を明文化する。

### 戦略性 vs 手軽さ → 戦略性優先

- 毎ターンの判断が重い設計を目指す
- 死因が常にプレイヤーの判断に帰着するようにする
- AP制限により「何を諦めるか」の選択を強いる
- ボス戦では特殊スキルへの対応が生死を分ける

### ランダム性 vs 再現性 → バランス型

- マップ配置や手札はランダムだが、スキルで運をカバーできる設計
- 同じシードなら同じ展開を再現可能（テスト・攻略研究に有用）
- 運だけでクリアはできないが、運で即死もしない程度のランダム性
- 「この状況でどう判断するか」がゲームの核であり、ランダム性はその状況を生む手段
