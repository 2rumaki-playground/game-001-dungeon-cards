# カード仕様

## 共通仕様
すべてのカードは以下を持つ：
- 名前
- AP コスト
- 効果
- 使用条件

### 方向パラメータについて
一部のカード（移動カード、攻撃カードなど）は、カード使用時に**方向を選択**する必要がある。
- 方向はカードの固有属性ではなく、**使用時のパラメータ**として扱う
- 同じカード種別（例：移動カード）は1つのカードIDで管理され、デッキ内に複数枚存在する
- 使用時にプレイヤーが上/下/左/右の4方向から選択する
- この設計により、データ管理（カードID、重複カード数、UI表示）がシンプルになる

## 移動カード

### 仕様
- カード種別：移動カード（1種類のカードIDとして扱う）
- **方向パラメータ**：使用時にプレイヤーが方向を選択（上 / 下 / 左 / 右）
- APコスト：[constants.md](./constants.md) を参照
- 効果：選択した方向に1マス移動
- 移動失敗条件（いずれの場合もAPは消費され、カードは使用扱いとなり捨て札へ移動）：
  - 移動先がマップ外（境界を超える場合）
  - 移動先が壁タイル
  - 移動先に敵が存在する場合
- 移動成功時、移動先のタイルに応じた効果が発生する
  - 階段タイルに到達した場合：階層遷移が発生（詳細は [rules.md](./rules.md) の「階層遷移」を参照）

### データ表現
- 実装上、移動カードは単一のカードID（例：`card_move`）を持つ
- デッキ内では同じカードIDが複数枚存在する（枚数は [constants.md](./constants.md) を参照）
- カード使用時、UIで4方向から1つを選択するインターフェースを提供する
- テストでは `{cardId: "card_move", direction: "up"}` のような形式で表現可能

## 攻撃カード

### 仕様
- カード種別：攻撃カード（1種類のカードIDとして扱う）
- **方向パラメータ**：使用時にプレイヤーが方向を選択（上 / 下 / 左 / 右）
- APコスト：[constants.md](./constants.md) を参照
- 効果：選択した方向1マス先の敵にダメージを与える（ダメージ量は [constants.md](./constants.md) 参照）

### 攻撃の成立条件
攻撃が成立するのは以下の条件をすべて満たす場合のみ：
- 指定方向1マス先がマップ内（境界内）である
- 指定方向1マス先が壁タイルではない
- 指定方向1マス先に敵が存在する

### 攻撃の不成立
攻撃が不成立となるケース：
- 指定方向1マス先がマップ外（境界を超える場合）
- 指定方向1マス先が壁タイル
- 指定方向1マス先に敵が存在しない（床、階段、またはプレイヤー自身のみの場合）

**いずれの場合も AP は消費され、カードは使用扱いとなり捨て札へ移動する**

### データ表現
- 実装上、攻撃カードは単一のカードID（例：`card_attack`）を持つ
- デッキ内では同じカードIDが複数枚存在する（枚数は [constants.md](./constants.md) を参照）
- カード使用時、UIで4方向から1つを選択するインターフェースを提供する
- テストでは `{cardId: "card_attack", direction: "down"}` のような形式で表現可能

## 突進カード

### 仕様
- カード種別：突進カード（1種類のカードIDとして扱う）
- **方向パラメータ**：使用時にプレイヤーが方向を選択（上 / 下 / 左 / 右）
- APコスト：[constants.md](./constants.md) を参照
- 効果：選択した方向に最大2マス移動する（移動距離は [constants.md](./constants.md) を参照）

#### 解決処理
突進カードは以下の順序で処理される：

1. **1マス目の移動判定**
   - 移動先がマップ外、壁タイル、または敵が存在する場合：
     - **移動失敗**：プレイヤーは移動せず、その場に留まる
     - APは消費される
     - 処理終了
   - 移動先が床または階段タイルで、敵が存在しない場合：
     - **1マス移動成功**
     - 2マス目の移動判定へ進む

2. **1マス目の階段判定**
   - 1マス移動後のタイルが階段の場合：
     - **階層遷移が発生**（[rules.md](./rules.md) の「階層遷移」を参照）
     - 2マス目の移動は行わない
     - 処理終了
   - 1マス移動後のタイルが床の場合：
     - 2マス目の移動判定へ進む

3. **2マス目の移動判定**
   - 移動先がマップ外、壁タイル、または敵が存在する場合：
     - **移動停止**：1マス目で停止
     - APは消費済み
     - 処理終了
   - 移動先が床または階段タイルで、敵が存在しない場合：
     - **2マス移動成功**
     - 2マス目の階段判定へ進む

4. **2マス目の階段判定**
   - 2マス移動後のタイルが階段の場合：
     - **階層遷移が発生**（[rules.md](./rules.md) の「階層遷移」を参照）
   - 2マス移動後のタイルが床の場合：
     - 処理終了

#### 停止条件の優先順位
突進は以下の条件のいずれかで停止する（優先度順）：

1. **1マス目での停止**：
   - マップ外
   - 壁タイル
   - 敵が存在する

2. **1マス目の階段での停止**：
   - 階層遷移により処理終了

3. **2マス目での停止**：
   - マップ外
   - 壁タイル
   - 敵が存在する

4. **2マス目到達**：
   - 上記の停止条件に該当せず、2マス移動完了

#### 重要な仕様
- **APは常に消費され、カードは使用扱いとなり捨て札へ移動する**（移動が失敗した場合も含む）
- 移動の各段階で階段判定が行われ、階段に乗った時点で階層遷移が発生する
- 階層遷移が発生した場合、残りの移動処理はキャンセルされる
- 他のキャラクター（敵）との衝突では、移動が停止するのみで、ダメージは発生しない（攻撃カードではないため）
- ※ 移動可否判定の詳細は `rules.md` の「移動可否の判定」を参照（正）

### データ表現
- 実装上、突進カードは単一のカードID（例：`card_rush`）を持つ
- デッキ内では同じカードIDが複数枚存在する（枚数は [constants.md](./constants.md) を参照）
- カード使用時、UIで4方向から1つを選択するインターフェースを提供する
- テストでは `{cardId: "card_rush", direction: "right"}` のような形式で表現可能
