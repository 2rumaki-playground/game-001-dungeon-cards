# デッキ構築仕様

## 概要

デッキ構築システムの仕様を定義する。
敵を倒すことでカードを確率でドロップし、デッキをカスタマイズできる。

---

## カード獲得

### 獲得の仕組み

- 各敵タイプには**固有のカード**と**ドロップ確率**が設定されている（ドロップ確率テーブルは [constants.md](./constants.md) 参照）
- プレイヤーが敵を撃破するたびに確率判定を行い、当選した場合にカード交換画面が表示される
- 判定にはゲーム内RNG（シード制御済み）を使用する

### 敵タイプとカードの対応

| 敵タイプ | 獲得カード |
|---------|-----------|
| 通常敵 | 移動カード |
| 射撃敵 | 移動カード |
| 重装敵 | 強攻撃カード |
| 俊敏敵 | ジャンプカード |
| 召喚敵 | 待機カード |
| 盾持ち敵 | 攻撃カード |
| ミニボス | 攻撃カード |
| ボス | 待機カード |

### カウンターの管理

- 撃破数・被弾数のカウンターはUI/統計用に引き続き管理される
- カウンターは**ラン（1回のゲームプレイ）単位**で管理される
- フロアをまたいでカウンターは累計される（リセットされない）
- 新しいゲームを開始すると、カウンターはすべて0にリセットされる
- カード獲得判定にはカウンターを使用しない（確率判定のみ）

---

## カード交換

### 交換のタイミング

- 敵撃破時にドロップ判定に当選した場合、**撃破演出の完了後にカード交換画面**が表示される
- 同一ターン内に複数のドロップが発生した場合、キューに積まれ、先頭から順次処理される

### 交換の手順

デッキ枚数は固定（[constants.md](./constants.md) 参照）のため、カード獲得は常に**入れ替え方式**となる：

1. 「[敵名]を倒して[カード名]を獲得！」のメッセージが表示される
2. 現在のデッキからカード一覧が表示される
3. プレイヤーは入れ替えたいカードを1枚選択する
4. 選択されたカードがデッキから除去され、獲得したカードがデッキに追加される

### スキップ

- 交換画面では「スキップ」を選択可能
- スキップした場合、デッキは変更されない（獲得カードは破棄される）

---

## ゲームフローへの統合

### 敵撃破時のフロー

プレイヤーが敵を撃破した際のフローは以下の順序で処理される：

1. **撃破カウンターの更新**：その敵タイプの撃破数を+1する
2. **ドロップ判定**：RNGで確率判定を行い、当選した場合はカード交換エントリをキューに追加する
3. **キュー処理**：撃破演出後、キューが空でなければ先頭から順次カード交換画面を表示する
   - プレイヤーがデッキから1枚を選択して入れ替え（またはスキップ）
4. **落選時**：通常の撃破処理のみ（カード交換は発生しない）

### 被弾カウンターの更新

- 敵からダメージを受けた際に、攻撃元の敵タイプの被弾カウンターが+1される
- 通常攻撃、ミニボスの強化攻撃、ボスの範囲攻撃のすべてが対象

### フロアクリア後のフロー

プレイヤーが階段に到達、または「次の階層へ」ボタンを押した際のフロー：

1. **階層遷移**：[rules.md](./rules.md) の「階層遷移」に従い、次の階層へ進行する

※ デッキ構築では、専用のカード報酬画面やカード除去イベントは用いず、敵撃破時の即時交換のみをデッキ変化手段として扱う
