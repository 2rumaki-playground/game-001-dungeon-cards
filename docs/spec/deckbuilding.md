# デッキ構築仕様

## 概要

デッキ構築システムの仕様を定義する。
敵を倒すことでカードを獲得し、デッキをカスタマイズできる。

---

## カード獲得

### 獲得の仕組み

- 各敵タイプには**固有のカード**が対応している（対応表は [constants.md](./constants.md) 参照）
- プレイヤーが敵を撃破した際、**獲得条件**を満たしていれば、その敵固有のカードを獲得できる
- 条件を満たしていない場合、カードの獲得は発生しない

### 敵タイプとカードの対応

| 敵タイプ | 獲得カード |
|---------|-----------|
| 通常敵 | 移動カード |
| 重装敵 | 強攻撃カード |
| 俊敏敵 | ジャンプカード |
| ミニボス | 攻撃カード |
| ボス | 待機カード |

### 獲得条件

各敵タイプごとに条件が設定されている（具体的な閾値は [constants.md](./constants.md) 参照）。
条件の種類：

| 条件タイプ | 説明 |
|-----------|------|
| 撃破数（defeat_count） | その敵タイプの累計撃破数が閾値に達している |
| 被弾数（hit_count） | その敵タイプから受けた累計被弾回数が閾値に達している |

- 各敵タイプに1つ以上の条件が設定される
- 複数条件がある場合、AND（すべて満たす）またはOR（いずれか満たす）で結合される
- 結合方式は敵タイプごとに個別に設定される

### カウンターの管理

- 撃破数・被弾数のカウンターは**ラン（1回のゲームプレイ）単位**で管理される
- フロアをまたいでカウンターは累計される（リセットされない）
- 新しいゲームを開始すると、カウンターはすべて0にリセットされる

---

## カード交換

### 交換のタイミング

- 敵撃破時に獲得条件を満たした場合、**即座にカード交換画面**が表示される
- 撃破演出の完了後に交換画面に遷移する

### 交換の手順

デッキ枚数は固定（[constants.md](./constants.md) 参照）のため、カード獲得は常に**入れ替え方式**となる：

1. 「[敵名]を倒して[カード名]を獲得！」のメッセージが表示される
2. 現在のデッキからカード一覧が表示される
3. プレイヤーは入れ替えたいカードを1枚選択する
4. 選択されたカードがデッキから除去され、獲得したカードがデッキに追加される

### スキップ

- 交換画面では「スキップ」を選択可能
- スキップした場合、デッキは変更されない（獲得カードは破棄される）

---

## ゲームフローへの統合

### 敵撃破時のフロー

プレイヤーが敵を撃破した際のフローは以下の順序で処理される：

1. **撃破カウンターの更新**：その敵タイプの撃破数を+1する
2. **獲得条件の判定**：更新後のカウンターで条件を評価する
3. **条件達成時**：カード交換画面を表示する
   - プレイヤーがデッキから1枚を選択して入れ替え（またはスキップ）
4. **条件未達時**：通常の撃破処理のみ（カード交換は発生しない）

### 被弾カウンターの更新

- 敵からダメージを受けた際に、攻撃元の敵タイプの被弾カウンターが+1される
- 通常攻撃、ミニボスの強化攻撃、ボスの範囲攻撃のすべてが対象

### フロアクリア後のフロー

プレイヤーが階段に到達、または「次の階層へ」ボタンを押した際のフロー：

1. **階層遷移**：[rules.md](./rules.md) の「階層遷移」に従い、次の階層へ進行する

※ デッキ構築では、専用のカード報酬画面やカード除去イベントは用いず、敵撃破時の即時交換のみをデッキ変化手段として扱う
