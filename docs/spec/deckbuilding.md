# デッキ構築仕様

## 概要

v1.2 で導入するデッキ構築システムの仕様を定義する。
v1 では初期デッキ（18枚・5種類）が固定されていたが、v1.2 ではカードの入手・除去を通じてデッキをカスタマイズできるようになる。

---

## カード入手

### 入手タイミング

- プレイヤーが**階段に到達した時点**で、そのフロアで撃破した敵の数に応じてカード報酬が発生する
- 敵を1体も撃破していない場合、報酬は発生しない

### 報酬の選択肢数

- 撃破した敵の数がそのまま選択肢の数になる
  - 1体撃破 → 選択肢1枚
  - 2体撃破 → 選択肢2枚
  - 3体撃破（全敵撃破） → 選択肢3枚
- 選択肢の最大数は、そのフロアの敵の初期配置数（[constants.md](./constants.md) 参照）と一致する

### 報酬画面

- 階段到達時に報酬画面を表示する
- プレイヤーは提示された選択肢から**1枚を選択**してデッキに追加する
- **スキップ可能**：カードを1枚も追加しない選択もできる
- 報酬画面の後、階層遷移処理が実行される（[rules.md](./rules.md) の「階層遷移」を参照）

### カード選択肢の生成

1. [レアリティシステム](#レアリティシステム)に基づいてレアリティを決定する
2. 決定されたレアリティの[カードプール](#カードプール)からランダムにカードを選出する
3. 選択肢の生成にはゲーム共通のRNGを使用する（[rules.md](./rules.md) の「ランダム配置の再現性方針」に従う）
4. **同一カード種別の重複を許容する**（例：選択肢3枚がすべて移動カードになる場合がある）

## カード除去

### 除去タイミング

- そのフロアの**全敵を撃破**した場合、確率でカード除去イベントが発生する
- 発生確率は [constants.md](./constants.md) を参照
- 除去イベントの判定にはゲーム共通のRNGを使用する（[rules.md](./rules.md) の「ランダム配置の再現性方針」に従う）
- 除去イベントはカード報酬の**前**に発生する（フロアクリア → 除去イベント → 階段到達 → カード報酬 → 階層遷移）

### 除去の制約

- デッキの総枚数（山札＋手札＋捨て札）が最小枚数（[constants.md](./constants.md) 参照）以下の場合、除去イベントは発生しない
- **スキップ可能**：除去イベントが発生しても、カードを除去しない選択ができる

### デッキ上限到達時の入手

- デッキの総枚数がデッキ最大枚数（[constants.md](./constants.md) 参照）に達している場合、カード報酬は**入れ替え方式**となる
  1. まずデッキから1枚を選択して除去する
  2. その後、報酬カードを1枚選択して追加する
- この入れ替えにおいても、スキップ（追加しない）は可能

## カードプール

### プール構成

報酬の選択肢に出現するカードは以下のプールから選出される：

| カード種別 | レアリティ | プール対象 |
|-----------|-----------|-----------|
| 移動カード | コモン | ○ |
| 攻撃カード | コモン | ○ |
| 待機カード | コモン | ○ |
| 強攻撃カード | アンコモン | ○ |
| 回復カード | アンコモン | ○ |
| 突進カード | レア | ○ |
| 貫通攻撃カード | レア | ○ |

- 各カードのレアリティは [constants.md](./constants.md) を参照
- 初期デッキに含まれるカード種別も報酬プールに含まれる
- 待機カードも報酬プールに含まれる

---

## レアリティシステム

### レアリティの種類

カードは以下の3段階のレアリティを持つ：

| レアリティ | 説明 |
|-----------|------|
| コモン | 基本的なカード。入手しやすい |
| アンコモン | やや強力なカード。中程度の入手確率 |
| レア | 強力なカード。入手が難しい |

### 出現率

報酬の選択肢における各レアリティの出現率（具体的な数値は [constants.md](./constants.md) を参照）：

| レアリティ | 出現率 |
|-----------|--------|
| コモン | [constants.md](./constants.md) 参照 |
| アンコモン | [constants.md](./constants.md) 参照 |
| レア | [constants.md](./constants.md) 参照 |

- 各選択肢ごとに独立してレアリティ判定を行う
- レアリティ判定後、そのレアリティに属するカード種別から均等確率で1枚を選出する

## 新カード仕様（v1.2追加）

### 回復カード

#### 仕様
- カード種別：回復カード（1種類のカードIDとして扱う）
- 方向パラメータ：なし
- APコスト：[constants.md](./constants.md) を参照
- 効果：プレイヤーのHPを回復する（回復量は [constants.md](./constants.md) 参照）
- HP上限：プレイヤーの初期HP（[constants.md](./constants.md) 参照）を超えない
- 成立条件：**常に成立**（HPが最大でもAP消費してカード使用扱いとなり捨て札へ移動する）
- レアリティ：アンコモン（[constants.md](./constants.md) 参照）

#### 戦略的意図
- 防御的プレイスタイルをサポートし、長期戦での生存率を向上させる
- HP管理という新たな戦略的判断をプレイヤーに提供する

#### データ表現
- 実装上、回復カードは単一のカードID（例：`card_heal`）を持つ
- 方向選択は不要（使用時に即座に効果が発動する）
- テストでは `{cardId: "card_heal"}` のような形式で表現可能

### 貫通攻撃カード

#### 仕様
- カード種別：貫通攻撃カード（1種類のカードIDとして扱う）
- **方向パラメータ**：使用時にプレイヤーが方向を選択（上 / 下 / 左 / 右）
- APコスト：[constants.md](./constants.md) を参照
- 効果：選択した方向に射程（[constants.md](./constants.md) 参照）マスまで貫通し、射程内の**全ての敵**にダメージを与える（ダメージ量は [constants.md](./constants.md) 参照）
- 射程：[constants.md](./constants.md) 参照（壁で遮断される）
- 壁の遮断：射程内に壁タイルがある場合、壁より先の敵には攻撃が届かない

#### 攻撃の成立条件
攻撃が成立するのは以下の条件をすべて満たす場合のみ：
- 指定方向の射程内（壁で遮断されるまで）に敵が1体以上存在する

#### 攻撃の不成立
攻撃が不成立となるケース：
- 射程内（壁で遮断されるまで）に敵が存在しない

**いずれの場合もAPは消費され、カードは使用扱いとなり捨て札へ移動する**

#### 戦略的意図
- 複数の敵を効率的に処理する手段を提供する
- 俊敏敵（スカウト）の高機動に対する対策として機能する
- 射程による間合い管理という新たな戦術を追加する

#### データ表現
- 実装上、貫通攻撃カードは単一のカードID（例：`card_pierce`）を持つ
- カード使用時、UIで4方向から1つを選択するインターフェースを提供する
- テストでは `{cardId: "card_pierce", direction: "up"}` のような形式で表現可能

## ゲームフローへの統合

### フロアクリア後のフロー

プレイヤーが階段に到達した際のフローは以下の順序で処理される：

1. **撃破数の集計**：そのフロアで撃破した敵の数を集計する
2. **カード除去イベント判定**：全敵撃破の場合、確率で除去イベントが発生する
   - 発生した場合、除去画面を表示しプレイヤーが除去するカードを選択（またはスキップ）
3. **カード報酬**：撃破数に応じた選択肢を提示する
   - プレイヤーが1枚を選択してデッキに追加（またはスキップ）
   - デッキ上限到達時は入れ替え方式
4. **階層遷移**：[rules.md](./rules.md) の「階層遷移」に従い、次の階層へ進行する
