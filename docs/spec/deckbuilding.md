# デッキ構築仕様

## 概要

v1.2 で導入するデッキ構築システムの仕様を定義する。
v1 では初期デッキ（6枚・3種類）が固定されていたが、v1.2 ではカードの入手・除去を通じてデッキをカスタマイズできるようになる。

---

## カード入手

### 入手タイミング

- プレイヤーが**階段に到達した時点**、または**全敵撃破後の「次の階層へ」ボタンを押した時点**で、そのフロアで撃破した敵の数に応じてカード報酬が発生する
- 敵を1体も撃破していない場合、報酬は発生しない

### 報酬の選択肢数

- 撃破した敵の数がそのまま選択肢の数になる
  - 1体撃破 → 選択肢1枚
  - 2体撃破 → 選択肢2枚
  - 3体撃破 → 選択肢3枚（以降、撃破数に応じて増加）
- 選択肢の最大数は、そのフロアの敵の初期配置数（[constants.md](./constants.md) 参照）と一致する

### 報酬画面

- 階段到達時、または「次の階層へ」ボタン押下時に報酬画面を表示する
- プレイヤーは提示された選択肢から**1枚を選択**してデッキに追加する
- **スキップ可能**：カードを1枚も追加しない選択もできる
- 報酬画面の後、階層遷移処理が実行される（[rules.md](./rules.md) の「階層遷移」を参照）

### カード選択肢の生成

1. [レアリティシステム](#レアリティシステム)に基づいてレアリティを決定する
2. 決定されたレアリティの[カードプール](#カードプール)からランダムにカードを選出する
3. 選択肢の生成にはゲーム共通のRNGを使用する（[rules.md](./rules.md) の「ランダム配置の再現性方針」に従う）
4. **同一カード種別の重複を許容する**（例：選択肢3枚がすべて移動カードになる場合がある）

## カード除去

### 除去タイミング

- プレイヤーが階段に到達、または「次の階層へ」ボタンを押したタイミングで、全敵撃破済みであれば除去イベント発生判定を行う
- 発生確率は [constants.md](./constants.md) を参照
- 除去イベントの判定にはゲーム共通のRNGを使用する（[rules.md](./rules.md) の「ランダム配置の再現性方針」に従う）
- 除去イベントはカード報酬の**前**に発生する（階段到達またはボタン押下 → 除去イベント → カード報酬 → 階層遷移）

### 除去の制約

- デッキ枚数は固定（[constants.md](./constants.md) 参照）のため、単独のカード除去イベントは発生しない
- **スキップ可能**：除去イベントが発生しても、カードを除去しない選択ができる

### カード入手（入れ替え方式）

- デッキ枚数が固定のため、カード報酬は常に**入れ替え方式**での受け取りとなる
  - 報酬カードを受け取ることを選んだ場合の手順：
    1. まずデッキから1枚を選択して除去する
    2. その後、報酬カードを1枚選択して追加する
- スキップを選んだ場合、**入れ替え処理自体を行わず、除去も追加も行わない**（デッキ枚数は変化しない）

## カードプール

### プール構成

報酬の選択肢に出現するカードは以下のプールから選出される：

| カード種別 | プール対象 |
|-----------|-----------|
| 移動カード | ○ |
| 攻撃カード | ○ |
| 待機カード | ○ |
| 強攻撃カード | ○ |
| 回復カード | ○ |
| ジャンプカード | ○ |
| 貫通攻撃カード | ○ |

- 各カードのレアリティは [constants.md](./constants.md) を参照（レアリティの正典は constants.md）
- 初期デッキに含まれるカード種別も報酬プールに含まれる
- 待機カードも報酬プールに含まれる

---

## レアリティシステム

### レアリティの種類

カードは以下の3段階のレアリティを持つ：

| レアリティ | 説明 |
|-----------|------|
| コモン | 基本的なカード。入手しやすい |
| アンコモン | やや強力なカード。中程度の入手確率 |
| レア | 強力なカード。入手が難しい |

### 出現率

報酬の選択肢における各レアリティの出現率（具体的な数値は [constants.md](./constants.md) を参照）：

| レアリティ | 出現率 |
|-----------|--------|
| コモン | [constants.md](./constants.md) 参照 |
| アンコモン | [constants.md](./constants.md) 参照 |
| レア | [constants.md](./constants.md) 参照 |

- 各選択肢ごとに独立してレアリティ判定を行う
- レアリティ判定後、そのレアリティに属するカード種別から均等確率で1枚を選出する

## 新カードの追加（v1.2）

v1.2 では、新たに以下のカードが追加される。
カード自体の仕様（効果・コスト・成立条件など）は [cards.md](./cards.md) を正として管理する。

- **回復カード** — 詳細は [cards.md](./cards.md) の「回復カード」を参照
- **貫通攻撃カード** — 詳細は [cards.md](./cards.md) の「貫通攻撃カード」を参照

これらのカードは既存のレアリティ別カードプールに組み込まれ、前述の「報酬生成ルール」（レアリティ判定 → 同レアリティ内から均等確率で選出）に従って報酬候補として提示される。
レアリティは [constants.md](./constants.md) を参照。

※ 新カードを追加・変更する際は、まず [cards.md](./cards.md) を更新し、その上で本ファイルに「報酬プール上の扱い」や「デッキ構築フロー上の影響」があれば追記する運用とする。

## ゲームフローへの統合

### フロアクリア後のフロー

プレイヤーが階段に到達、または「次の階層へ」ボタンを押した際のフローは以下の順序で処理される：

1. **撃破数の集計**：そのフロアで撃破した敵の数を集計する
2. **カード除去イベント判定**：全敵撃破の場合、確率で除去イベントが発生する
   - 発生した場合、除去画面を表示しプレイヤーが除去するカードを選択（またはスキップ）
3. **カード報酬**：撃破数に応じた選択肢を提示する
   - プレイヤーが1枚を選択してデッキに追加（またはスキップ）
   - デッキ上限到達時は入れ替え方式
4. **階層遷移**：[rules.md](./rules.md) の「階層遷移」に従い、次の階層へ進行する
