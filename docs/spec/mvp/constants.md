# 定数・前提（MVP）

> **重要：このファイルはすべての数値定数の正典 (Single Source of Truth) です**  
> - 他のドキュメント（`rules.md` など）で数値を記載する場合は、このファイルを参照してください
> - 数値を変更する際は、まずこのファイルを更新してから、他のドキュメントを確認・更新してください

## 行動関連
- 最大AP：3
- ターン開始時AP：3
- 初期手札上限：5（仮）

## 移動
- 移動方向：上 / 下 / 左 / 右
- 移動距離：基本1マス

## 戦闘
- 敵行動回数：1ターン1回
- 敵移動距離：1マス
- 攻撃範囲：隣接1マス（隣接の定義は [glossary.md](./glossary.md) 参照：4近傍、上下左右のみ）

### HP（体力）
- プレイヤー初期HP：10
- 敵初期HP：3

### ダメージ
- 攻撃カードのダメージ：1
- 強攻撃カードのダメージ：3
- 敵の攻撃ダメージ：1

## マップ生成
- マップサイズ：横7マス × 縦7マス
- 階段の数：各階層に1つ
- 敵の初期配置数：3体

※ 数値はバランス調整で変更される前提
