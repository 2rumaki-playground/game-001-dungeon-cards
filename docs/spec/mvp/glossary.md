# 用語集

## ターン
- プレイヤーターン → 敵ターン の1サイクル

## AP（Action Point）
- プレイヤーが1ターンに使用できる行動リソース

## 山札（Draw Pile）
- カードを引く元のデッキ
- 山札が空になった場合、捨て札をシャッフルして新しい山札とする

## 手札（Hand）
- 現在使用可能なカード群

## 捨て札（Discard Pile）
- 使用済みカードが置かれる場所
- 山札が空になった際に、シャッフルされて山札に戻る

## タイル
- マップを構成する1マス単位のセル

## HP（Hit Point / 体力）
- プレイヤーおよび敵が持つ生命力の数値
- ダメージを受けると減少し、0 以下になると死亡する

## ゲームオーバー
- プレイヤーが敗北し、ゲームが終了した状態
- MVP では、ゲームオーバー後の再開機能は実装しない

## マンハッタン距離
- 2点間の距離を、縦横の移動のみで測定した距離
- 計算式：|x1 - x2| + |y1 - y2|
- 敵の移動方向決定に使用される

## 階層（Floor）
- ダンジョンの各階層を表す単位
- 各階層は独立したマップを持つ
- 階段を使用することで次の階層へ進むことができる

## 階層遷移（Floor Transition）
- プレイヤーが階段タイルに移動することで発生する、次階層への移行処理
- 旧階層のマップは破棄され、新階層のマップが生成される
- プレイヤーのターン状態、AP、デッキ状態は保持される
- 詳細は [rules.md](./rules.md) の「階層遷移」を参照
