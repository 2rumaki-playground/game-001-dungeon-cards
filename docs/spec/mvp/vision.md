# ビジョン / ゲーム概要

## ジャンル
- タイル制ローグライク × デッキ構築カードゲーム

## コアコンセプト
- ローグライクの「位置取り・間合い」
- カードゲームの「手札・リソース管理」
  を同時に考えさせるゲーム体験を目指す。

## プレイヤー体験
- 1手ごとに「移動か？攻撃か？」を選択
- AP (Action Point :アクションポイント) の制限により無駄な行動がリスクになる
- デッキ構築によってプレイ感が変化する（※MVP対象外、将来の拡張予定）

## MVPでの制約
- **デッキ構築なし**: 初期デッキ固定で全階層をプレイ
- カード入手・追加の手段は実装しない

## MVP のゴール
- ダンジョンを進み、より深い階層へ到達する
- 明確な勝利条件は設定しない
