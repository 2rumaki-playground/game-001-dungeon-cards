# Frontend

Dungeon Cards のフロントエンド開発環境。

## 技術スタック

- **Vite** - ビルドツール
- **TypeScript** - 型安全な JavaScript
- **PixiJS v8** - 2D レンダリング
- **Biome** - リント・フォーマット

## セットアップ

```bash
pnpm install
```

## 開発

```bash
pnpm run dev      # 開発サーバー起動 (http://localhost:3000)
pnpm run build    # 本番ビルド
pnpm run lint     # Biome チェック
pnpm run format   # コードフォーマット
```
