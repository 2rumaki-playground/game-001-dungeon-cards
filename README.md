# game-001-dungeon-cards-02

タイル制ローグライク × デッキ構築カードゲーム

## コンセプト

ローグライクの「位置取り・間合い」とカードゲームの「手札・リソース管理」を同時に考えさせるゲーム体験を目指しています。

- 1手ごとに「移動か？攻撃か？」を選択
- AP（アクションポイント）の制限により無駄な行動がリスクになる
- APコストの異なるカードの使い分けが戦略の鍵
- デッキ構築によってプレイ感が変化する
